## Authority and model
JSON remains the sole behavioral authority. A generator validates JSON through the existing schema/semantic validator and emits ContractData.tla from it. A handwritten generic formal/Session.tla consumes that finite data; it never generates native code. Track state, previousState, event, effects. Init records initial state, same previousState, a reserved __initial__ event not in event alphabet and empty effects. Next nondeterministically selects exactly one row matching current state, assigns previousState'=state, event'=row.event, state'=row.nextState, effects'=row.effects. Spec=Init /\ [][Next]_vars. Stuttering is absence of a processed event, not repeated effect execution; fields are last-transition observations, not a history or credentials store.

Check declared state/event/effect closure, maximum effect length and transition observation soundness against the table. Additionally check total/deterministic table via the existing validator. Do not add fairness or promise liveness: environment may never supply refresh success/failure. Check deadlocks on the full model without artificial state constraints or depth limits; the event alphabet and total table allow further events. Native equivalence remains bounded by existing traces; no formal refinement of arbitrary Swift/Kotlin programs is claimed.

## Independent data bridge
